# 用例 007：文件资源管理器（新建 / 重命名 / 删除）

## 前置
- 桌面干净，没有打开的窗口。
- 桌面上**没有**名为 `qa-test` 的文件夹（如果有，先删掉再开始，并在报告里说明）。

## 说明
本机工具只有**左键**点击，右键菜单用不了。所以用资源管理器顶部的**命令栏按钮**：
`新建`（带下拉箭头）、`重命名`、`删除`（垃圾桶图标）。

## 步骤
1. 打开文件资源管理器：按 `Win+E`，或点任务栏的文件夹图标。
2. 在左侧导航栏点「桌面」，右边显示桌面上的文件。
3. 点命令栏的「**新建**」，在展开的菜单里选「**文件夹**」。
4. 新建出来的文件夹会处于可改名状态，直接输入 `qa-test`，按 **Enter**。
5. 确认列表里出现名为 `qa-test` 的文件夹。
6. **单击选中**这个文件夹，点命令栏的「**删除**」（垃圾桶图标）。
7. 如果弹出「确认删除」之类的对话框，选择确认。

## 通过标准
- 第 4 步之后，列表里出现 `qa-test` 文件夹（名字必须一字不差）。
- 第 6/7 步之后，`qa-test` 从列表里消失，桌面上也没有残留。
- 全程没有报错对话框。

## 取证要求
每步截图：资源管理器打开 → 点「桌面」后的视图 → 新建菜单展开 → 改名过程中 → 出现 `qa-test` → 选中它 → 删除后消失。
最后一张必须能看清列表里已经没有 `qa-test`。
