# 用例 006：商业游戏 Plague Inc 启动与开局

## 前置
- 桌面干净，没有打开的窗口。
- 桌面上有一个名字是 `Plague Inc` 的快捷方式（红黑色图标）。
- 游戏当前没有运行。

## 步骤
1. 打开桌面上的 `Plague Inc` 快捷方式（**单击选中，按 Enter**；本机合成双击对程序不生效）。
2. 等待游戏启动。会先播放几段黑底红字的开场画面（例如 `INFECT PATIENT ZERO`、`WIPE OUT HUMANITY`），可能需要 30–60 秒，不要因为"看起来没反应"就判失败。
3. 出现主菜单：左侧一列按钮 `Single Player / Load Game / Multiplayer / Scenario Creator / Stats & Leaderboards / Options / Help & Info / Exit Game`。
4. 如果屏幕中间弹出广告弹窗（标题 `PLAGUE INC: THE CURE IS OUT NOW!`，按钮 `Play` / `Close`），点 `Close` 把它关掉。
5. 点左侧的 `Single Player`。
6. 选择第一个病原体（Bacteria / 细菌），点右下角的开始/确认按钮。
7. 如果要求给病原体命名，随便输入一个名字（例如 `test`），然后确认。
8. 等待进入游戏，观察世界地图。

## 通过标准
- 出现世界地图：能看到大陆轮廓、国家名（如 CHINA）、左下角疾病面板、右下角世界进度。
- **右上角的游戏内日期在推进**（例如从 `14-5-2014` 开始往后走），说明游戏在实时运行，而不是一张卡死的静态图。

## 取证要求
每步截图：桌面快捷方式 → 开场画面 → 主菜单 → 关掉弹窗后 → 病原体选择 → 命名 → 世界地图。
**世界地图必须间隔至少 5 秒截两张**，用来证明日期/感染数在变化。

> 上一轮（2026-10-24）执行时留下的缺口：测试员在等待启动期间连按 Enter，按键被消息队列缓冲，
> 窗口一创建就连点跳过了开场和主菜单，导致这两屏**没有截图**。下一轮请明确要求：
> **等待期间只截图、不按键；确认窗口出现后再操作**。开场阶段建议每 10 秒截一张。
