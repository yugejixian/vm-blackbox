# 用例 003：安装第三方软件（安装向导）

## 前置
- 桌面干净，没有打开的窗口。
- 桌面上有一个**安装包文件**：`Everything-Setup.exe`（橙色放大镜图标，图标文字可能显示为截断的 `Everything...`）。
  **注意：它是安装包文件，不是已经装好的程序快捷方式。** 判断依据：查看文件类型/属性、或双击后出现的是安装向导而不是程序窗口。
- Everything 尚未安装（开始菜单里没有它，设置→应用里也没有）。

## 步骤
1. 打开桌面上的 `Everything-Setup.exe`：**单击选中后按 Enter**（本机合成双击对程序不生效；双击无反应时改用这个动作，并在报告里注明是等价动作）。
2. 按安装向导走完流程：接受协议 → 保持默认安装选项 → 安装 → 完成。
3. 等待安装结束。

## 通过标准
- 安装向导走完，全程没有报错对话框
- 安装完成后 Everything 主窗口出现（有搜索框和结果列表），或开始菜单里能找到 Everything

## 取证要求
向导每一屏各截一张图（第一屏、协议页、安装页、完成页），加安装完成后的程序窗口。
