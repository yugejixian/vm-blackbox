# 用例 008：浏览器打开本地网页并正确渲染

## 前置
- 桌面干净，没有打开的窗口。
- 桌面上有一个文件 `qa-test-page.html`（白色齿轮图标或浏览器图标，不是快捷方式）。
  基线快照 `zh-cn-clean` 里已经包含它，不需要手工投递；如果缺失，按 handoff「投递被测文件」用
  `VBoxManage guestcontrol copyto` 从 `D:\null_work\assets\qa-test-page.html` 补。
- 浏览器（Edge）当前没有打开。

## 步骤
1. 打开桌面上的 `qa-test-page.html`（**单击选中，按 Enter**；本机双击对程序不生效）。
2. 如果弹出「选择打开方式」的对话框，选择 Microsoft Edge 并确认；如果弹出协议/默认应用提示，按提示继续。
3. 等浏览器窗口出现，页面加载完成。
4. 在页面上找到标题行和那行彩色文字，逐字核对。

## 通过标准
- 浏览器窗口出现，地址栏显示的是本地文件路径（`file:///...qa-test-page.html` 或类似）。
- 页面正文里能看到并读清这三行：
  1. `虚拟机测试页 QA-2026`
  2. `中文渲染正常：你好，虚拟机测试员`
  3. `This line should be GREEN.`
- 第 3 行文字**必须是绿色**，不是黑白灰。

## 取证要求
每步截图：桌面上的文件 → 打开方式对话框（如果出现）→ 浏览器加载中 → 加载完成后的完整页面。
最后一张要能同时看清三行文字，其中第三行的颜色也要能判断出来。
